# FURNETURE_BOT

Telegram-бот-каталог мебели. Пользователь выбирает категорию, применяет
фильтр, открывает карточку товара и просматривает фотографии и контакты для
заказа.

## Возможности пользователя

- Главное меню запускается командой `/start`.
- Доступны категории: спальная, кухонная и мягкая мебель, столы и стулья,
  тумбы и комоды, матрасы, кровати и шкафы.
- Спальная, мягкая мебель и столы со стульями фильтруются по стране:
  `Россия` или `Турция`.
- Кухонная мебель фильтруется по типу: `Прямая` или `Угловая`.
- Для остальных категорий товары открываются сразу списком.
- Перед списком показывается количество найденных товаров.
- Карточка товара содержит фотографии, категорию, название, описание, тип,
  страну производства, дату добавления, контакты и ссылку на Instagram.
- На каждом уровне есть возврат в список или главное меню.

## Текущее состояние

Пользовательская часть подключена в `main.py` через роутер
`handlers.backend.user`.

Админская часть пока не подключена к диспетчеру. В проекте есть состояния FSM
для создания категорий, добавления и удаления мебели, но полноценные
админские обработчики находятся в разработке.

Контакты в карточке берутся из `.env`. Instagram пока задан константой в
`handlers/backend/user.py`.

## Структура проекта

```text
main.py                         запуск бота и подключение роутеров
settings/config.py              загрузка токена и контактов
handlers/backend/user.py        пользовательские обработчики каталога
handlers/admin/                 место для админских обработчиков
keyboard/user_keyboards.py      inline-клавиатуры каталога
database/models.py              модели SQLAlchemy
database/crud.py                запросы списка и карточки товара
database/engine.py              асинхронное подключение к SQLite
alembic/                        миграции базы данных
states/states.py                состояния FSM для будущей админ-панели
```

## Требования

- Python 3.12 или совместимая версия Python 3;
- Telegram Bot Token;
- зависимости из `requirements.txt`.

## Установка и запуск

Из корня проекта выполните:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создайте `.env` на основе шаблона:

```bash
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=токен_бота
WHATSAPP_CONTACT=номер_whatsapp
TELEGRAM_CONTACT=@username_или_ссылка
```

Примените миграции и запустите бота:

```bash
alembic upgrade head
python main.py
```

Для локального окружения проекта:

```bash
./venv/bin/alembic upgrade head
./venv/bin/python main.py
```

## Данные каталога

Товар хранится в таблице `furniture` и должен иметь `name`, `description`,
`category_name`, `category_id` и `created_at`. Для фильтруемых категорий также
используются:

- `country`: `Россия` или `Турция`;
- `subcategory`: `Прямая` или `Угловая` для кухонной мебели.

Фотографии хранятся в `furniture_photos`. Для отправки в Telegram используется
поле `file_id`, полученное от Telegram при загрузке фотографии.

## База данных и миграции

Проект использует SQLite, SQLAlchemy и Alembic. Файл базы находится в:

```text
database/database.db
```

После изменения моделей создавайте новую миграцию:

```bash
alembic revision --autogenerate -m "Описание изменения"
alembic upgrade head
```

Не редактируйте уже применённые миграции: новую схему добавляйте отдельной
ревизией.

## Подключение админ-панели

Админский роутер подключается в `main.py` рядом с пользовательским:

```python
from handlers.admin.some_module import router as admin_router

dispatcher.include_router(user_router)
dispatcher.include_router(admin_router)
```

Пользовательскую и админскую части нужно запускать одним процессом с одним
Telegram-токеном. Два отдельных процесса с polling могут конфликтовать.

Админ-панель должна использовать существующие поля модели `Furniture` и те же
значения фильтров. Доступ администратора следует проверять по `User.is_admin`.
