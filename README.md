# FURNETURE_BOT

Telegram-бот-каталог мебели. Пользователь выбирает категорию, применяет
фильтр, открывает карточку товара и просматривает фотографии и контакты для
заказа.

## Возможности пользователя

- Главное меню запускается командой `/start`.
- Доступны категории: спальная, кухонная и мягкая мебель, столы и стулья,
  тумбы и комоды, матрасы, кровати и шкафы.
- Спальная, мягкая мебель и столы со стульями фильтруются по странам,
  которые реально есть у товаров в базе.
- Кухонная мебель фильтруется по подкатегориям, которые реально есть у товаров
  в базе, например `Прямая` или `Угловая`.
- Для остальных категорий товары открываются сразу списком.
- Перед списком показывается количество найденных товаров.
- Список разбит на страницы по 5 товаров с кнопками перехода между страницами.
- При открытии карточки и возврате сохраняется текущая страница и фильтр.
- Карточка товара содержит фотографии, категорию, название, описание, тип,
  страну производства, дату добавления, контакты и ссылку на Instagram.
- На каждом уровне есть возврат в список или главное меню.

## Текущее состояние

Пользовательская часть подключена в `main.py` через роутер
`handlers.backend.user`, оформление заявок — через `handlers.backend.order`.

Админ-панель работает по команде `/admin` и доступна двум типам
администраторов:

- указанным в `.env` через `ADMIN_ID` (один telegram_id или несколько
  через запятую);
- пользователям с флагом `is_admin` в таблице `users`, который
  устанавливается вручную в базе:

```sql
UPDATE users SET is_admin = 1 WHERE telegram_id = <ваш_telegram_id>;
```

Возможности панели:

- добавление и удаление категорий (удаление категории удаляет её товары);
- добавление товара: название, описание, категория, тип кухни или страна,
  контакты WhatsApp/Telegram, цена, фотографии;
- удаление товара с выбором из списка постранично;
- просмотр и удаление подкатегорий (метка снимается с товаров);
- раздел «Заявки»: постраничный список заказов и карточка с именем, телефоном,
  username покупателя и сменой статуса (новая → в работе → выполнена / отменена);
- при подтверждении заявки покупателем администраторам приходит сообщение
  в Telegram с номером заявки, товаром, именем, телефоном и username
  (получатели — админы из `ADMIN_ID` и из таблицы `users`);
- телефон заявки проверяется и нормализуется в международный формат E.164
  (`docs/adr/0001-phone-normalization.md`): локальные записи трактуются
  как российские, нераспознанный номер — повторный ввод с подсказкой.

Стандартные категории добавляются миграцией `9c3e2a1b7d4f` и затем отображаются
в главном меню непосредственно из таблицы `categories`. Миграция `f8b2d4c6a9e1`
добавляет товарам контакты (`whatsapp_contact`, `telegram_contact`),
`c4d9e7f2a8b3` — имя и телефон покупателя в заявке (и создаёт саму таблицу
`orders`, отсутствовавшую в старых миграциях), а `e9f4b8c2d6a7` — цену товара
(целые рубли; пусто — «не указана»).

Instagram пока задан константой в `handlers/backend/user/texts.py`.

## Требования

- Python 3.12 или совместимая версия Python 3;
- Telegram Bot Token;
- зависимости из `requirements.txt`.

## Установка и запуск

Из корня проекта выполните:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Создайте `.env` на основе шаблона:

```bash
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=токен_бота
ADMIN_ID=ваш_telegram_id
```

Примените миграции и запустите бота:

```bash
alembic upgrade head
python main.py
```

Для локального окружения проекта:

```bash
./venv/bin/alembic upgrade head
./venv/bin/python main.py
```

## Данные каталога

Товар хранится в таблице `furniture` и должен иметь `name`, `description`,
`category_name`, `category_id` и `created_at`. Для фильтруемых категорий также
используются:

- `country`: `Россия` или `Турция`;
- `subcategory`: значение подкатегории для кухонной мебели.

Контакты карточки (`whatsapp_contact`, `telegram_contact`) администратор
указывает при добавлении товара; если поле пустое, в карточке показывается
«не указан».

Меню фильтров строится динамически через уникальные значения `country` и
`subcategory`. Поэтому новая страна или подкатегория, добавленная админ-панелью
вместе с товаром, появится в меню без изменения кода.

Фотографии хранятся в `furniture_photos`. Для отправки в Telegram используется
поле `file_id`, полученное от Telegram при загрузке фотографии.

## База данных и миграции

Проект использует SQLite, SQLAlchemy и Alembic. Файл базы находится в:

```text
database/database.db
```

После изменения моделей создавайте новую миграцию:

```bash
alembic revision --autogenerate -m "Описание изменения"
alembic upgrade head
```

Не редактируйте уже применённые миграции: новую схему добавляйте отдельной
ревизией.

## Админ-панель

Админский роутер подключён в `main.py` рядом с пользовательским. Все его
callback_data начинаются с `adm:` и не пересекаются с каталогом:

```python
dispatcher.include_router(admin_router)
dispatcher.include_router(user_router)
dispatcher.include_router(order_router)
```

Пользовательскую и админскую части нужно запускать одним процессом с одним
Telegram-токеном. Два отдельных процесса с polling могут конфликтовать.

Доступ проверяется по флагу `User.is_admin`. Панель использует существующие
поля модели `Furniture` и те же значения фильтров, что и каталог.
