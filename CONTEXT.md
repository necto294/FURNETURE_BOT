# Контекст предметной области

Глоссарий терминов мебельного бота. Без деталей реализации.

## Заявка

### Покупатель
Человек, оформивший заявку на товар через бота. Не совпадает с пользователем
Telegram: у него могут быть пустые профильные имя/username, поэтому контакт
для связи собирается формой отдельно.

### Телефон покупателя
Единственный надёжный канал связи с покупателем для подтверждения заявки.
Вводится покупателем в свободной форме; принимаются номера любых стран,
никакой одной страны по умолчанию не предполагается.

### Контакт товара
Телефон WhatsApp и Telegram-адрес, которые администратор указывает товару
для прямой связи покупателя с магазином. Телефонная часть контакта
подчиняется тем же правилам нормализации, что и телефон покупателя;
Telegram-адрес телефоном не является и не проверяется как телефон.

### Международный формат
Канонический способ записи телефона: плюс, код страны, полный номер
(например `+79001234567`). Целевое состояние данных: любой принятый телефон
хранится в международном формате.

### Локальный формат
Запись номера без явного кода страны: с транковым префиксом (`8900…` в России,
`0…` во многих странах) или вовсе без него (`900…`). Локальная запись сама по
себе не определяет страну — она интерпретируется через страну по умолчанию.
Покупатель из другой страны обязан использовать международный формат с `+`.

### Страна по умолчанию
Россия (регион RU). Применяется только к номерам без `+`: локальную запись
невозможно интерпретировать без контекста, а текущий бизнес-контекст делает
Россию ожидаемым регионом. Это умолчание парсинга, а не утверждение о том,
что бот ориентирован только на Россию.

### Повторный ввод
Единственная реакция на нераспознанный телефон: сообщение об ошибке с
подсказкой указать код страны через `+` и просьбой ввести номер снова.
Заявка не отклоняется, отдельный диалог уточнения страны не заводится,
FSM остаётся в том же состоянии.
